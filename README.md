# Питомец Финни

Игра для Android, которая учит детей 7–11 лет обращаться с карманными деньгами.

Ребёнок заводит питомца и получает игровые финкоины (Φ). Каждую неделю он решает, сколько потратить на обязательное (еду и уход), сколько на желаемое (игрушки и украшения) и сколько отложить в копилку на мечту. От этих решений зависит, как питомец чувствует себя сейчас и как он растёт дальше. Ошибиться не страшно: игра объясняет, что произошло, и подсказывает, как поправить, а достигнутый прогресс не отнимается.

Настоящих денег, рекламы, покупок внутри приложения, регистрации и сбора данных нет. Игра работает без интернета, всё хранится только на устройстве.

**Версия 1.1 (сборка 2), пакет `ru.finni.pet`, Android 5.1 и новее.** Подписанные APK и AAB лежат в корне репозитория и продублированы в релизе `v1.1.0`.

## Что умеет

- знакомство с целью игры и тремя решениями, игровое имя вместо настоящего;
- семь питомцев с разными характерами, по три окраса и три стадии роста;
- план бюджета на три направления и сравнение плана с фактом в конце недели;
- лавка из 12 товаров: шесть обязательных и шесть желаемых;
- копилка на три цели сразу, четыре готовые цели и своя, срок до цели по средней сумме пополнения;
- 12 заданий по темам «Планирование бюджета», «Копим на цель», «Покупки и платежи»;
- события недель, история всех операций, прогресс, финсловарь из 16 слов;
- раздел для взрослого за простым барьером: прогресс, начисление финкоинов за дела вне игры, сброс и удаление профиля;
- демонстрационный режим: готовый профиль, все задания открыты, недели проходятся подряд.

## Быстрый запуск

**На телефоне.** Скачать `Питомец Финни 1.1.apk` из корня репозитория или из релиза `v1.1.0`, открыть файл на устройстве и разрешить установку из этого источника. Разрешений приложение не просит.

**В браузере.** Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
cd app
npm install
npm run dev
```

Игра откроется на `http://localhost:5173`. Удобно включить режим телефона: F12, затем значок телефона.

**Проверить сценарий целиком.** На экране «Как это работает» есть кнопка «Демонстрационный режим»: профиль создаётся сразу, все задания открыты, а недели можно проходить подряд без ожидания.

## Команды

Из папки `app`:

```bash
npm run dev       # сервер разработки
npm test          # 154 автотеста
npm run build     # сборка веб-части в app/dist
npm run preview   # посмотреть собранную версию
```

## Сборка APK

Понадобятся JDK 17 и Android SDK (Platform 34, Build-Tools 34.0.0).

```bash
cd app
npm install
npm run build
npx cap add android
npm run android:icons
npx cap sync android
node scripts/android-manifest.mjs
node scripts/android-signing.mjs
cd android
./gradlew assembleRelease
```

Для подписи в корне репозитория нужен файл `keystore.properties` с путём к ключу и паролями (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`). Ни ключа, ни этого файла в репозитории нет. Готовый APK появится в `app/android/app/build/outputs/apk/release/`. Для магазина рядом собирается AAB – командой `gradlew bundleRelease`, файл появится в `app/android/app/build/outputs/bundle/release/`.

## Что где лежит

```
├── README.md
├── Питомец Финни 1.1.apk      подписанная сборка для установки на телефон
├── Питомец Финни 1.1.aab      та же сборка в формате магазина
├── docs/                      документация, инструкция, презентация, история изменений и состав решения
├── Материалы для RuStore/     карточка приложения, иконка 512x512, восемь скриншотов
└── app/
    ├── public/assets/         изображения: питомцы, комната, заставка, иконки
    ├── scripts/               иконки, версия, манифест и подпись для Android-сборки
    └── src/
        ├── content/           учебный контент: задания, товары, цели, события, термины, питомцы
        ├── engine/            игровая экономика и автотесты
        ├── state/             действия игрока и сохранение профиля
        ├── screens/           экраны
        ├── components/        общие элементы интерфейса
        └── styles/            цвета, размеры, шрифты
```

Учебный контент отделён от кода. Чтобы добавить задание, товар, цель или термин, достаточно дописать объект в нужный файл в `app/src/content`, логику трогать не нужно.
